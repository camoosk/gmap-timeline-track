# GMap Timeline Track

Web-based visualizer for Google Maps Timeline exports.

## Status

Initial project scaffold. The application is designed to process Google Maps Timeline JSON locally in the browser, without uploading personal location history to a server.

## Planned MVP

- Import Google Maps Timeline JSON
- Interactive map and route visualization
- Date/time filtering
- Stops and visit details
- Trip playback
- Basic travel statistics

## Privacy

Timeline data should remain client-side by default. No location history is sent to a backend in the initial architecture.
